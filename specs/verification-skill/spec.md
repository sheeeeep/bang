# bang 项目验证技能

在 `.agents/skills/verify-bang/` 中维护验证技能、五项功能地图和验证脚本，让首次接手项目的 agent 也能按步骤运行命令、核对结果并保留证据。

脚本复用仓库已有的 PTY 驱动。每次验证使用独立的临时 HOME 和 Git 项目，不修改产品代码，也不安装全局依赖。

## 验收要求

- 技能文档包含 Launch、Doctor、Drive、Evidence、Cleanup 和 Helpers 六个章节。
- 功能地图覆盖项目选择、归集、目录配置、agent 指引和安装指南。
- 至少完整执行一项功能的真实用户操作，并检查产生的文件变化。
- 清理临时目录和进程后，证据文件仍然保留。
- 明确记录已验证和未验证的入口，不将部分通过写成全部通过。
