# bang 验证地图

此目录是用户行为验证的维护源；先确定功能和全部入口，再决定本次覆盖。只证明一个便利入口，不代表其余入口已验证。

## 基线前提

使用上级 SKILL.md 的 Launch 和 Doctor：源码命令、独立 HOME、独立 Git 项目、独立证据目录，无安装和认证。各配方从全新基线开始；不要串用上次的配置、备份或链接。主界面为 PTY，非 TTY 的编号选择也是正式入口。

## 驱动约定

管道配方运行在 Launch 的隔离 bash 中；`REPO` 指源码，`HOME` 和当前目录均指临时数据。配方内 `test`、`cmp` 和 Python 断言失败即停止；日志末尾的 `rc=0` 只在前置命令全部通过后打印。PTY 操作用既有 `PtySession` 的提示等待，不靠坐标或固定 sleep。

## 证据与跳过报告

记录功能 ID、具体入口、命令/按键、输出、退出码和结果文件。预览/取消还要验证无副作用；变更要通过文件或 Git 的只读第二视角核实。日志、配置副本、备份证据放在 EVIDENCE；清理只删 SCRATCH。未跑的入口明确写“未验证”；端到端首轮只要求跑一项，不把地图全标为通过。
