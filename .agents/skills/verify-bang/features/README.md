# bang 验证地图

本目录记录 bang 各项功能的操作步骤和预期结果。验证前先查看该功能有哪些入口，再确定本次检查哪些入口。不要因为一个入口通过，就把其余入口也标为通过。

## 基线前提

先按上级 SKILL.md 的 Launch 准备环境，再运行 Doctor。使用源码命令，无需安装或登录。每个功能都从独立的 HOME、Git 项目和证据目录开始，不沿用上次的配置、备份或链接。

终端选择界面用 PTY 验证；非 TTY 环境中的编号选择也要单独检查。

## 驱动约定

管道命令在 Launch 准备的独立 bash 中运行。`REPO` 指向源码目录，`HOME` 和当前目录指向本次临时目录。

`test`、`cmp` 或 Python 断言失败时立即停止；只有前面的命令全部通过，才打印日志末尾的 `rc=0`。使用 `PtySession` 时，等待预期提示出现再操作，不依赖屏幕坐标或固定等待时长。

## 证据与跳过报告

每次验证都记录功能 ID、具体入口、命令或按键、输出、退出码和结果文件。预览或取消后，检查文件没有变化；确认变更后，再读取文件或运行 Git 命令核对结果，不能只看成功提示。

日志、配置副本和备份证据放在 EVIDENCE，清理时只删除 SCRATCH。生成技能后的首次验收只要求跑通一项功能，其余入口应明确标为“未验证”。
